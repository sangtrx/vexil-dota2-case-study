# Kaggle private verification package — four deterministic parity runs

This package is intentionally not published. It contains derived
**previously inspected validation** probabilities only, NOT a fresh
holdout, live trading signals, private Quant Bible source text,
credentials or customer records.

- Dataset: private sangtruong/vexil-bible-development-qa-20261113
- K1: private CPU notebook for recomputing 58 proper scores,
  145 phase/calibration rows and match-weighted sensitivity.
- K2: private CPU notebook checking 20 directional (10 complementary) ordered-series-bucket
  rank reversal and 3,000 series OOB selection draws. Six buckets overlap in time, so this is NOT a strict chronological CV or official PBO.
- K3: private CPU notebook recomputing all 28
  simultaneous max-|t| bootstrap intervals (5,000 draws)
  and the 38-record incomplete historical trial ledger.
- K4: private CPU notebook audits approximate game intervals,
  showing that four of five prior six-bucket boundaries overlap.
  It verifies four approximate non-overlapping temporal components
  of 62/2/3/36 games and all 116 component model scores.
- All four kernels use Internet OFF, GPU OFF and private dataset.
  The Kaggle notebooks do NOT fetch OpenDota or retrain models.

The notebooks repeat the same predefined calculations with source
SHA-256 checks. This is reproducibility evidence, not
independent confirmation of their statistical validity.

## Reproduction

The four notebook directories, metadata and input staging directory
have been generated by prepare_private_runs.py. Before cloud execution,
authenticate the Kaggle CLI locally, using the browser-based flow:

    kaggle auth login

Do not paste API tokens into this repository, chat or notebook.
Then:

    bash kaggle/run_private_kernels.sh

This is a one-time **private dataset creation**, so a second invocation
will intentionally stop rather than silently replace input data.
After all kernels show COMPLETE, run:

    bash kaggle/verify_hosted_kernels.sh

The second script downloads hosted output receipts and compares every
numerical result with the local verified receipts. Kaggle status
screenshots or a pushed notebook version alone are not sufficient
to claim hosted completion. If authentication is absent, no Kaggle
runs have occurred; local source checks are still valid.

The original 500-match cold Kaggle Run All predates this package and
is documented separately in the original take-home repo QA. Do not
count it as one of these four new hosted verifications.
